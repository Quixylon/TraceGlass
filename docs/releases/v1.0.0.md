# TraceGlass v1.0.0

**Бесплатное нативное приложение для обводки на iPhone. Без подписки, рекламы, встроенных покупок и платной разблокировки функций.**

Самостоятельный open-source проект Quixylon. Не связан с одноимёнными или похожими приложениями из App Store; покупать приложение в App Store для использования этого проекта не нужно.

## Скачать и установить

Скачай **TraceGlass.ipa** из Assets этого релиза. Это unsigned Release для физического iPhone, arm64 / iPhoneOS, а не сборка симулятора. Подпиши и установи её своим Apple Account через Sideloadly или AltStore. Требуется iOS 17+.

Инструкция: [INSTALL_WINDOWS.md](https://github.com/Quixylon/TraceGlass/blob/v1.0.0/INSTALL_WINDOWS.md).

## Что входит

- Lightbox с одновременными жестами, точной фиксацией Lock и удержанием Unlock.
- Фильтры, подготовка линий, inversion/threshold/edges, слои, crop/perspective и сетки.
- Локальные проекты, autosave, undo/redo, настройка яркости и физическая калибровка.
- Paper Track и World Anchor, Ghost и временное скрытие reference.
- Liquid Glass на iOS 26+, Metal particle transitions и Reduce Motion.

## Файлы релиза

- `TraceGlass.ipa` — приложение для последующей подписи при установке.
- `TraceGlass-1.0.0-Source.zip` — полный проект, assets, shaders, tests, документация, лицензия и build scripts.
- `TraceGlass-1.0.0-Verification.zip` — результаты CI, xcresult, скриншоты и сведения о бинарнике.
- `SHA256SUMS.txt` — контрольные суммы файлов.

## Ограничения

Сборка и тесты симулятора не подтверждают точность AR на реальной бумаге, 120 FPS и установку после resign. Lock не отключает системные жесты iOS. Интерфейс английский. Полный список находится в `KNOWN_LIMITATIONS.md` исходников.

Все изображения обрабатываются локально. Приложение не содержит сервера, аккаунтов или загрузки пользовательских изображений. Лицензия MIT.
