# Установка на iPhone с Windows

1. Установи [Sideloadly](https://sideloadly.io/). Если он попросит компоненты Apple, используй ссылки iTunes/iCloud с его официального сайта.
2. Подключи iPhone по USB, разблокируй и нажми «Доверять» на телефоне.
3. Перетащи `TraceGlass.ipa` в Sideloadly, выбери iPhone и введи **свой** Apple Account.
4. Нажми **Start** и заверши вход/подпись. IPA не привязана к чужому аккаунту.
5. Если iOS попросит: включи **Настройки → Конфиденциальность и безопасность → Режим разработчика**, перезагрузи iPhone и подтверди. Доверие профилю, если требуется: **Основные → VPN и управление устройством**.

Открой TraceGlass → Choose Image → выбери рисунок → настрой → LOCK. Разблокировка — удержание маленького замка.

Бесплатная подпись обычно действует 7 дней: включи автоматическое обновление в Sideloadly или повторно установи ту же IPA с тем же аккаунтом и bundle ID. Не удаляй приложение перед обновлением — в нём хранятся проекты.

Альтернатива: импорт этой IPA в AltStore Classic с собственным аккаунтом.

Источники: [Sideloadly FAQ](https://sideloadly.io/faq), [Apple Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).
